# Article Translator

웹 문서를 원문 구조를 보존한 한국어 Markdown으로 번역한다. 개인 기본 저장 위치는 Obsidian vault의 `Sources/Translations/`이며, 사용자가 지정한 산출물·경로가 우선한다.

## 원문 확보

- URL이 없으면 요청한다. 현재 세션에서 사용 가능한 웹 조회·브라우저·연결 도구로 본문과 이미지 출처를 확보한다. GitHub 문서는 사용 가능한 `gh`도 활용할 수 있다.
- 도구 이름이나 설치 상태를 가정하지 않는다. 조회 실패 시 다른 사용 가능한 경로를 확인하고, 원문을 얻지 못한 부분은 알린다.
- 페이지 일부만 확보했다면 완역으로 보고하지 않는다. 번역 가능 범위와 누락을 명시한다.

## 번역 규칙

- heading 계층, 섹션·단락 순서, 목록, 표, 강조, 링크를 보존한다. 요약이나 원문에 없는 설명을 본문에 추가하지 않는다.
- 코드·명령어·식별자·고유명사는 원문을 유지한다. 코드 주석은 필요할 때 번역한다.
- 기술 용어는 첫 등장에 한국어(영어)를 병기하고 이후 자연스러운 표현을 사용한다. 불확실한 의미는 원문을 병기한다.
- 문어체(~다, ~이다)로 쓰되 원문의 톤과 의미를 유지한다.
- 닫는 `**` 다음에는 띄어쓰기를 둔다. 수식은 의미를 유지한 LaTeX로 표현한다.

## 이미지와 다이어그램

- 원문 이미지 URL과 alt text를 수집해 같은 위치에 `![alt](url)`로 넣는다. alt text는 원문을 유지하고 상대 URL은 원문 기준으로 해석한다.
- 이미지 URL을 사용할 수 없지만 도형·관계·내용을 직접 확인했다면 Mermaid나 표로 재현하고 재현본임을 표시한다. 내용을 확인하지 못했다면 누락을 알린다.
- ASCII 다이어그램은 관계를 보존한 표나 Mermaid로 변환한다.
- Mermaid는 `<br>`로 줄바꿈하고, 노드는 어두운 배경과 `color:#fff`를 사용한다. subgraph 배경은 기본값을 유지한다.
- 색상 기본값: 핵심 `#1565C0`, 성공 `#2E7D32`, 분기 `#E65100`, 오류 `#C62828`.
- Mermaid를 만들었다면 현재 사용 가능한 렌더러로 구문과 결과를 확인한다. 검증 도구가 없으면 렌더링 미확인으로 보고한다.

## 저장 규칙

기본 vault:
`/Users/sskim/Library/Mobile Documents/iCloud~md~obsidian/Documents/Note`

- 저장 전에 실제 vault와 현재 양식을 확인한다. 예상 경로가 없으면 다른 위치에 새 vault를 만들지 말고 경로를 확인한다.
- `Sources/Translations/` 아래 평면 구조로 저장한다. 카테고리 폴더는 만들지 않는다.
- 주제 분류는 기존 vault의 `tags`/`topics` 관례를 따른다. 예를 들어 `tags: [til, spring]`처럼 기록한다.
- 파일명은 번역한 제목에서 특수문자를 제거하고 공백을 `-`로 바꾼다. 예: `효과적인-에이전트-구축하기.md`.
- frontmatter가 있으면 그 뒤 본문의 첫 줄을 `# 번역된 제목`으로 시작한다. 같은 파일이 있으면 읽어서 기존 번역·사용자 편집과 겹치는지 확인한다.

### 출처 헤더

```markdown
# 번역된 제목

> 이 글은 [사이트명]의 [원문 제목](원문 URL) 을 한국어로 번역한 글입니다.
> 원문 작성일: YYYY년 MM월 DD일 | 작성자: 저자명
```

원문 작성일·저자를 확인하지 못하면 해당 항목은 생략한다. 끝에는 `## 출처`와 원문 링크를 둔다.

## 관련 노트 연결

저장 후 같은 주제의 기존 노트를 검색해 연결 후보를 제시한다. 사용자가 관련 노트 수정까지 요청한 경우 해당 범위에서 `related_notes`의 wikilink를 추가하고, 그렇지 않으면 제안만 한다.

## 완료 확인

- 원문과 번역문의 섹션 순서·내용·코드·링크·이미지를 대조한다.
- 출처 헤더, 파일명, 저장 위치와 태그를 확인한다.
- 저장 경로, 원문 제목과 번역 제목, 원문 이미지 수와 재현 수, 누락·미확인 부분을 보고한다.
- README 갱신과 Git stage·commit·push는 번역 작업에 포함하지 않는다. 사용자가 따로 요청한 경우에만 수행한다.
